# 🍱 Daily Meal Planner — ตารางเมนูอาหารรายวัน

เว็บแอปวางแผนมื้ออาหารรายสัปดาห์ พร้อมสรุปปริมาณสารอาหาร (พลังงาน โปรตีน คาร์โบไฮเดรต ไขมัน)
เทียบกับเป้าหมายต่อวัน — เขียนด้วย **Flask** ไฟล์เดียว (`app.py`) และ **Tailwind CSS (CDN)**

---

## ✨ Features

| ฟีเจอร์ | รายละเอียด |
|---|---|
| กรองตามวัน | เลือกดูเฉพาะวันจันทร์–อาทิตย์ หรือรวมทั้งสัปดาห์ |
| การ์ดสรุปสารอาหาร | พลังงาน / โปรตีน / คาร์บ / ไขมัน พร้อม progress bar เทียบเป้าหมาย |
| ตารางเมนู | แยกสีตามมื้อ (เช้า กลางวัน เย็น ของว่าง) มีแถวรวมท้ายตาราง |
| เพิ่ม / ลบเมนู | ฟอร์มกรอกค่าสารอาหารเอง ลบได้ทีละรายการ |
| REST API | `/api/menu` และ `/api/summary` สำหรับต่อยอด |
| Responsive | ใช้งานได้ทั้งมือถือและเดสก์ท็อป |

---

## 📦 Requirements

- Python 3.8 ขึ้นไป
- Flask 2.x หรือใหม่กว่า
- การเชื่อมต่ออินเทอร์เน็ต (เพราะ Tailwind และฟอนต์โหลดผ่าน CDN)

## 🚀 Installation

```bash
# 1) clone หรือสร้างโฟลเดอร์โปรเจค
mkdir meal-planner && cd meal-planner

# 2) สร้าง virtual environment (แนะนำ)
python -m venv venv

# macOS / Linux
source venv/bin/activate

# Windows
venv\Scripts\activate

# 3) ติดตั้ง Flask
pip install flask
```

วางไฟล์ `app.py` ไว้ในโฟลเดอร์นี้

## 📖 Usage

### 1. ดูเมนูรายวัน
กดปุ่มชื่อวันด้านบน (จันทร์ – อาทิตย์) เพื่อกรองเฉพาะวันนั้น
กด **"ทุกวัน"** เพื่อดูเมนูทั้งสัปดาห์รวมกัน

### 2. อ่านการ์ดสรุป
การ์ด 4 ใบด้านบนแสดงยอดรวมสารอาหารของรายการที่กำลังแสดงอยู่
แถบสีคือเปอร์เซ็นต์เทียบกับเป้าหมายต่อวัน (ค่าเริ่มต้น 2000 kcal)

> ⚠️ เมื่อเลือก **"ทุกวัน"** ตัวเลขคือยอดรวมทั้ง 7 วัน เปอร์เซ็นต์จึงเกิน 100% เป็นปกติ

### 3. เพิ่มเมนู
เลื่อนลงไปที่การ์ด **"เพิ่มเมนูใหม่"** แล้วกรอก

| ช่อง | คำอธิบาย | ตัวอย่าง |
|---|---|---|
| วัน | วันในสัปดาห์ | พุธ |
| มื้อ | มื้อเช้า / กลางวัน / เย็น / ของว่าง | มื้อกลางวัน |
| ชื่อเมนู | ชื่ออาหาร (บังคับ) | ข้าวผัดกุ้ง |
| พลังงาน | หน่วย kcal | 520 |
| โปรตีน | หน่วยกรัม | 24 |
| คาร์โบไฮเดรต | หน่วยกรัม | 65 |
| ไขมัน | หน่วยกรัม | 18 |

กด **บันทึกเมนู** ระบบจะพากลับมาที่วันที่เพิ่งเพิ่ม

### 4. ลบเมนู
กดเครื่องหมาย **×** ที่ท้ายแถวในตาราง

## ⚙️ Configuration

ปรับค่าได้ที่ส่วนบนของ `app.py`

```python
# เป้าหมายสารอาหารต่อวัน
TARGET = {"calories": 2000, "protein": 60, "carbs": 300, "fat": 65}

# มื้ออาหาร — เพิ่ม/ลดได้ เช่น เติม "มื้อดึก"
MEALS = ["มื้อเช้า", "มื้อกลางวัน", "มื้อเย็น", "ของว่าง"]
```

> หากเพิ่มชื่อมื้อใหม่ อย่าลืมเพิ่มสีใน dict ของเทมเพลตด้วย
> (บล็อก `{'มื้อเช้า':'bg-amber-100 ...'}`) ไม่งั้นจะ error ตอน render

ส่วนเมนูตัวอย่างเริ่มต้นแก้ได้ที่ลิสต์ `MENU`

## 🔌 API Reference

### `GET /api/menu`
คืนรายการเมนูทั้งหมด หรือกรองด้วย query `?day=จันทร์`

```json
[
  {
    "id": 1,
    "day": "จันทร์",
    "meal": "มื้อเช้า",
    "name": "ข้าวต้มหมู + ไข่ต้ม",
    "calories": 350.0,
    "protein": 22.0,
    "carbs": 45.0,
    "fat": 9.0
  }
]
```

### `GET /api/summary`
คืนยอดรวมสารอาหารแยกรายวันทั้ง 7 วัน พร้อมเป้าหมาย

```json
{
  "target": { "calories": 2000, "protein": 60, "carbs": 300, "fat": 65 },
  "daily": {
    "จันทร์": {
      "calories": 1450.0,
      "protein": 89.0,
      "carbs": 178.0,
      "fat": 42.5,
      "percent_calories": 72.5
    }
  }
}
```

ตัวอย่างเรียกใช้:

```bash
curl http://127.0.0.1:5000/api/menu?day=จันทร์
curl http://127.0.0.1:5000/api/summary
```

## ⚠️ Limitations

- **ข้อมูลเก็บใน memory** — ปิดเซิร์ฟเวอร์แล้วข้อมูลที่เพิ่มจะหายไป กลับไปเป็นชุดตัวอย่างเดิม
- ค่าสารอาหารเป็น **ค่าประมาณ** ไม่ควรใช้อ้างอิงทางการแพทย์
- ยังไม่มีระบบผู้ใช้ / ล็อกอิน ทุกคนที่เข้าเห็นข้อมูลชุดเดียวกัน
- โหมด `debug=True` ใช้สำหรับพัฒนาเท่านั้น อย่านำขึ้น production
